# Stagehand – Proposals

This repository collects proposals for [Stagehand](https://apps.metaebene.me/en/stagehand/), written as Architecture Decision Records (ADRs). Each ADR documents a design question, the options considered, and the reasoning behind the chosen approach.

* [adr/0000-mqtt-device-category.md](adr/0000-mqtt-device-category.md) – devices that speak MQTT: subscribe to topics (triggers) and publish messages (steps).
* [adr/0000-webhook-device-category.md](adr/0000-webhook-device-category.md) – devices that speak plain HTTP: incoming calls (triggers) and outgoing calls (steps).
